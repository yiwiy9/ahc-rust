## 復習時の安全策

今回の主な事故は、探索パラメータを変更した後に、それから決まる移動・盤面・得点の一部だけが古いまま残ったことです。次の実装ではまず全再構築型を使います。

1. 近傍が直接変える `Parameters` を決める
2. `Parameters -> Output` を行う `rebuild` を1本にする
3. debug時は、出力・移動シミュレーション・内部評価をすべて素直な再計算と比較する
4. 正しさが確認できてから、差分更新へ置き換える

得点だけ一致しても、たまたま同じ得点になる誤った出力は検出できません。`debug_validate` では、得点に加えて「各手で現在位置から本当に到達できるか」「保持中の派生データが再構築結果と一致するか」を確認します。
