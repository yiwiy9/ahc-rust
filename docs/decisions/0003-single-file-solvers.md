# 0003: 生成元を分割し、競技中は1解法1ファイルにする

この改修はAHC073終了後の環境整備として行った。テンプレート・検証コード・ガイドの整備にはAI支援を利用している。保存済みの各コンテストの解法コードへ、この改修の新テンプレートを上書きしていない。

## 理由

070・071・073では、proconioと型付き入出力を持つ過去のa.rsをコピーする方が既存テンプレートより使いやすかった。raw StringのInputやVec<String>のOutput、編集箇所の分散、スクリプトとCLIの重複案内が負担だった。

## 決定

newの出力はConstructiveStateの貪欲版a.rs。題材はintro-heuristics Aとし、入出力・候補生成・軽量評価・状態更新を動く実装で示す。変更箇所をコメントで番号付けする。

テンプレートは保守のため分割するが、new時に一度だけ結合する。以降は生成済みbinが正本で、再生成しない。探索を変える場合はbinを複製し、追加部分を貼ってmainを変更する。探索ループ自体も自由に編集する。

ビーム・乱択・direct/rebuildの焼きなましについて、貼る部分とintroで動く完成例を両方用意する。新しい問題の近傍まで自動生成するものではない。

日常操作はscriptsへ統一する。既存CLIは実装・互換用。保存は同期実行で成功表示後に次へ進む。

## 検証

実際の生成コマンドから隔離workspaceを作る。binの手動複製、追加部分のコピペ、完成例、debug/release、export後のコード、intro公式toolsでの採点、保存と復元を確認する。既存contestの解法コードは書き換えない。
